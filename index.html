Which one is for me?

Pocket Server (39 EUR) is the handbook: you read it, follow the setup chapters and use the 51 ready-made files in your own way. Pocket Server Complete (299 EUR) is the same handbook plus a guided install with a check after every step, 23 more tools (a scheduler that wakes Claude at a set time, a network lock that limits where it can connect, and more) and the 825 tests. Want to be walked through one setup and have each step proven? Take Complete. Want to understand the idea first? Take the handbook.

What it costs and takes

No coding. Some learning: the handbook plans a full day for a first server; the Complete install guide plans one to two hours once a server exists. Running costs are a rented server and a Claude plan. As examples, checked on 25 November 2026: one provider (Hetzner) lists a server with 2 CPUs and 4 GB of memory from about 5.99 EUR per month plus VAT, and the Claude Pro plan, which includes Claude Code, lists at $20 per month when billed monthly. Prices change, and heavy use can need a bigger plan. Costs are flat where it counts: the server has a fixed monthly price, and the Claude plan is a monthly fee with usage limits (a five-hour and a weekly limit, per Anthropic's help page), not a per-use bill. Optional extra usage credits, if you switch them on, are billed at standard API rates, so enable them only if you accept that.

What if Claude breaks something?

It can. The setup limits the damage: Claude works on a separate server, not on your computer, as a user without administrator rights. A blocklist stops a listed set of destructive commands. A nightly encrypted backup comes with a restore test. You get an alert on your phone when something fails. The backup goes to the same server and to an encrypted copy at a second place (another server or a storage box): the handbook walks through it step by step, and the Complete install guide sets it up and tests a restore from it. It was tested with restic over SFTP; no specific storage provider was tested. There is no undo button, and the blocklist does not catch everything. If it does not work for you, both products come with a 30-day money-back guarantee, no reason needed.
